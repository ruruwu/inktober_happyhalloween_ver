# INKTOCTOBER｜十月繪圖占卜

每日翻開三張塔羅風格卡牌，從主題／角色、附加元素與色彩／風格三個卡池中，各抽一張作為繪圖靈感。

**網站：** https://ruruwu.github.io/inktober_happyhalloween_ver/

## 功能

- 三個各 50 張卡的池子，共 125,000 種組合。
- 同一天、同一版本的初始題目相同。
- 單張鎖定與重抽，或重抽所有未鎖定的牌。
- 複製題目、2026 年 10 月日曆、回顧每日紀錄。
- 紀錄僅存在自己的瀏覽器，可透過「關於這個工具」清除。
- favicon、社群分享標題、說明與預覽圖。

## 啟用 GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save。
部署成功後，使用上方網站網址分享，不要使用 repository 的 .git 網址。

## 資料與隱私

無登入、無分析追蹤、無資料上傳功能。紀錄以 localStorage 保存在目前瀏覽器，不會跨裝置同步；無痕模式或清除網站資料可能使紀錄消失。
下載版與 GitHub Pages 版的紀錄不會自動搬移。

## 本機開啟與更新

直接開啟 index.html 即可使用。修改並提交 main 分支的檔案後，GitHub Pages 會依設定重新部署。
分享預覽圖位於 og-preview.png；部分平台會快取預覽，更新不一定立即顯示。
